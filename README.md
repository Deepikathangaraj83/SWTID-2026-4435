# Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

## Project Description

This project automates the standard laptop procurement process using **ServiceNow Flow Designer**. When a standard laptop request is approved, the workflow automatically creates a **Catalog Task** and assigns it to the **Hardware** team for laptop configuration.

## Tools Used

* ServiceNow
* Flow Designer
* Service Catalog
* Catalog Tasks
